# Sports Analytics and Player Selection System

## Project Status
Completed — Final Year Project

## Overview

The Sports Analytics and Player Selection System is a Final Year Project focused on analyzing sports-related data and supporting player selection across 8 indoor and outdoor games.

The project includes 10 functions and metrics, such as identifying top-performing players and analyzing performance indicators like runs.

## Project Objectives

To develop an AI and Machine Learning–based sports player selection prediction system using historical player-performance data.
To collect, clean, preprocess, and integrate multi-sport player-performance datasets from eight sports: Cricket, Football, Rugby, Golf, Baseball, Volleyball, Table Tennis, and Badminton.
To identify and engineer relevant player-performance features that can be used to evaluate player suitability for selection.
To develop a Transformer-based deep learning model capable of learning complex relationships and patterns in player-performance data.
To classify players into two categories: Selected and Not Selected, based on their performance characteristics.
To evaluate the developed model using appropriate performance metrics, including Accuracy, Precision, Recall, F1-score, and Confusion Matrix.
To apply cross-validation to assess the reliability and consistency of the model's performance.
To develop a user-friendly system/interface that allows users to enter player information and obtain a selection prediction.
To provide a data-driven approach that can assist coaches, selectors, and sports organizations in evaluating players and supporting player-selection decisions.

## Key Functions

The project includes 10 functions and metrics.

Player Performance Analysis – analyzes historical player-performance data.
Data Preprocessing – cleans missing, inconsistent, and unsuitable data.
Feature Engineering – prepares relevant performance features for the model.
Player Selection Prediction – predicts whether a player should be selected or not.
Transformer-Based Prediction – uses the Transformer model to learn complex performance patterns.
Player Comparison – compares performance characteristics between players.
Player Ranking – ranks players according to their predicted selection suitability.
Accuracy – measures the overall correctness of the model.
Precision, Recall & F1-Score – evaluates classification performance for Selected/Not Selected classes.
Confusion Matrix & Cross-Validation – analyzes prediction errors and evaluates model consistency across different data splits.
